# Gummy Landing Page Assets

This folder contains the public assets for the Gummy landing page.

## Required Assets

### gummy-logo.png
- A bag-of-gummy-candy mark/logo
- Recommended size: 200x200px or higher
- Format: PNG with transparency
- Place this file in the root of the public folder

### Mobile Mock Screenshot (Optional)
- A screenshot showing the mobile interface
- Recommended size: 300x600px or similar mobile aspect ratio
- Format: PNG or JPG
- Replace the placeholder in the landing page

## Usage

The logo will be referenced in the navigation and footer components.
The mobile mock will replace the placeholder "device mock" panel in the hero section.
